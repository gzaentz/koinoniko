# Bittensor Update

Use this for Bittensor or subnet posts.

- Explain the useful economic or technical point in plain English.
- Avoid insider jargon unless the audience is explicitly the ecosystem.
- Make the subnet question concrete: what signal improves, who cares, and why now.
- Do not write a generic crypto hype post.
- Tie the point back to saved Facts & Context only when the connection is real.
